# 4차 제출용 실행 안내

## 실행

Visual Studio 2022에서 `26311038_Leeminsung_GameCraft.sln`을 열고 Debug / x64 또는 Release / x64를 빌드하여 실행합니다.
실행 파일만 사용할 때는 같은 폴더에 DirectX DLL과 resource 폴더를 함께 둡니다.
별도 Python 설치는 게임 실행에 필요하지 않습니다.

## 조작

| 키 | 기능 |
| --- | --- |
| Enter | 시작, 결과 화면에서 다시 시작 |
| A / D | 좌우 이동 |
| Space | 점프. 누르고 있어도 자동 연속 점프하지 않음 |
| S | 앉기. 높은 탄환 회피 |
| J | 사격. 누르면 연속 발사 |
| A/D + J | 총을 겨눈 채 이동 사격 |
| S + J | 앉은 자세를 유지하며 사격 |
| K | 수류탄 투척. 보유 수량 소비 |
| P / Esc | 일시정지 및 계속 |
| R | 결과 화면에서 다시 시작 |

## 한 판의 목표

사막 진입로, 보급소, 통신기지로 이어지는 5120픽셀 길이의 한 스테이지입니다.
병사 6명, 포탑 3개, 마지막 장갑 보스 1개가 등장합니다.
체력은 3이고, 피격 후 1.35초 동안 추가 피해를 받지 않습니다.
회복팩은 체력이 줄어 있을 때 획득하며, 수류탄 보급품은 2개씩 보충합니다.

보스 체력을 모두 없앤 뒤 오른쪽 끝 깃발까지 가면 클리어됩니다.
체력이 0이 되면 게임 오버가 됩니다. 두 결과 화면에서 Enter 또는 R로 같은 한 판을 새로 시작할 수 있습니다.
재시작 시 체력, 수류탄, 점수, 시간, 적, 보스, 아이템, 탄환, 카메라를 모두 초기화합니다.

## 플레이 팁

일반 적의 높은 탄환은 S로 앉아 피할 수 있습니다. 이동 중 날아오는 탄환과 보스의 낮은 탄환은 점프로 피합니다.
총알은 수평으로 날아가므로 발판 위에서 아래쪽 적을 쏠 때는 내려와 높이를 맞춥니다.
수류탄은 앞쪽으로 곡선을 그리며 날아가 주변 적에게 범위 피해를 줍니다.
철조망, 상자, 드럼통은 배경 소품이며, 점프해서 올라가는 철제 발판만 착지 판정이 있습니다.

캐릭터의 모든 자세는 동일한 캐릭터 시트와 공통 배율을 사용합니다.
앉기·점프·투척·사격 시에도 머리와 몸통의 크기를 다시 확대하지 않습니다.
총알과 발사 섬광은 해당 프레임의 실제 총구에서 나오며, 수류탄 크기는 서기·앉기 모두 같습니다.
병사는 사망 위치와 방향을 유지한 채 약 0.55초 동안 사라지고, 기계 적의 잔해는 약 0.9초 뒤 제거됩니다.

## 구현 및 검증 범위

GLC2D 기반 시작, 한 판 진행, 일시정지, 게임 오버, 클리어, 재시작을 구현했습니다.
이전 지정 형식인 CApplication 전역 객체와 Init, g2_Run, Destroy 순서를 유지했습니다.
기존 README 기획서는 수정하지 않았습니다.

`tools/run_checks.ps1`은 30/60/144FPS 이동, 점프 및 발판 착지, 월드와 카메라 경계, 일시정지, 전체 클리어, 게임 오버, 재시작 초기화를 검사합니다.
`tools/run_checks.ps1 -Visual`은 실제 게임 상태의 구간별 렌더링 확인 프로그램을 빌드합니다. 검증 창에서는 Space로 다음 장면을 확인합니다.
