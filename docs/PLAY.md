# 더스트파이어 작전 실행 안내

Visual Studio 2022에서 솔루션을 열어 Debug / x64 또는 Release / x64로 빌드하거나, GameCraft-3Stages.zip을 풀어 EXE를 실행합니다. ZIP의 resource 폴더와 DirectX DLL은 EXE 옆에 둡니다.

| 조작 | 동작 |
| --- | --- |
| Enter | 시작, 다음 스테이지 진입, 결과 화면 진행 |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| 발판 위 S / ↓ + Space | 발판을 통과해 아래로 내려가기 |
| J | 전방 사격. 누르고 있으면 연속 발사 |
| W / ↑ + J | 위 사격. 지상·공중 모두 가능 |
| 공중 S / ↓ + J | 아래 사격 |
| 지상 S / ↓ + J | 앉은 자세로 전방 사격 |
| K | 수류탄 투척 |
| P / Esc | 일시정지 또는 계속 |
| R | 실패한 스테이지 재시도 또는 최종 클리어 뒤 새 캠페인 |

| 스테이지 | 진행 |
| --- | --- |
| 01 사막 진입로 | 병사와 포탑이 지키는 사막 방어선을 지나 장갑 지휘차 격파 |
| 02 철제 보급기지 | 드론과 고가 포대가 있는 화물 기지. 위 사격으로 공중 목표나 고가의 공성포를 노릴 수 있음 |
| 03 야간 요새 | 달빛 아래의 요새 방어선. 최종 로켓 장갑차가 포물선 포탄, 저공 탄막, 조준 사격을 번갈아 사용 |

각 보스를 격파하고 끝의 깃발까지 가서 지면에 서면 클리어됩니다. 1·2스테이지 결과 화면에서 Enter를 누르면 다음 스테이지에 진입합니다. 점수와 보급품은 이어지고 체력이 최대 3까지 1 회복됩니다. 3스테이지를 끝내면 캠페인 결과가 표시됩니다.

실행 중 실패하면 현재 스테이지 입구에서 재도전합니다. 이전 스테이지 점수는 유지하고 실패한 스테이지의 적, 아이템, 탄환, 카메라는 초기화합니다. 이 체크포인트는 실행 중에만 유지됩니다.

기관총 보급품은 빠르고 강한 탄환을 최대 55발 제공합니다. 탄이 떨어지면 기본 소총으로 돌아갑니다. 회복팩은 체력이 줄었을 때 먹을 수 있고, 수류탄 보급품은 최대 2개를 보충합니다. 보급품을 얻으면 실제 증가량이 화면에 표시됩니다.

발판은 아래에서 통과하고 위에서 착지합니다. 수류탄은 지면, 발판 윗면 또는 적에 닿으면 폭발합니다. 적 머리 위 `!`는 공격 준비 신호입니다. 보스 체력과 회피 안내는 교전 중 하단에 표시됩니다. 점선은 탄환 경로를, 바닥의 주황색 표시는 박격포 착탄 범위를 나타냅니다. 다른 창으로 전환하면 일시정지되며, 게임 창에서 P 또는 Esc를 누르면 계속할 수 있습니다.

스테이지에서는 Negev Desert Loop, 보스 교전 중에는 Negev Fight Loop를 반복 재생합니다. 보스 격파 후에는 스테이지곡으로 돌아가며, 결과 화면에서는 배경음이 멈춥니다. 일시정지 메뉴에서는 재생 중인 곡이 이어집니다.

## 검증

`tools/run_checks.ps1`은 프레임률별 이동·연사, 짧은 입력, 발판과 수류탄 충돌, 위·아래 사격, 보스 공격 예고, 1~3스테이지 클리어와 체크포인트 재시도를 확인합니다. `-Visual` 옵션으로 렌더링 확인 프로그램을 빌드할 수 있습니다. 확인 창에서 1·2는 위·아래 사격, 6~9는 보급기지·요새와 각각의 보스, M은 박격포 경고, 0은 최종 결과입니다. Space를 누르면 다음 장면이 표시됩니다.

기존 CApplication 진입점과 960 × 600 화면을 유지했습니다.
