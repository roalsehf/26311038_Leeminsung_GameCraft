# DUSTFIRE OPS — 보급형 2D 런앤건 이미지 팩

사막 군사기지 한 스테이지에 필요한 픽셀아트 PNG를 개별 이미지로 분리한 팩입니다. C++/raylib, SDL, SFML 등의 2D 렌더러에서 텍스처로 불러올 수 있습니다.

이 팩은 **메탈슬러그에서 영감을 받은 오리지널 캐릭터·지형 디자인**입니다. 원작 게임 파일이나 원작 스프라이트를 복제한 것은 아닙니다.

## 폴더 구성

| 폴더 | 리소스 |
| --- | --- |
| `player/` | 기본 대기, 달리기 2장, 점프, 앉기, 피격, 사격(수평/상향/앉기), 수류탄 던지기, 재장전, 사망, 피격 플래시 |
| `enemies/` | 적 병사 6동작, 자동 포탑 6상태, 적 피격 플래시 |
| `boss/` | 탱크 보스 대기·이동·발포·파손·잔해·폭발·피격 플래시 |
| `tiles/` | 모래땅 4종, 철제 발판 3종, 사암·암석·콘크리트, 가시 함정, 나무다리 |
| `props/` | 나무상자, 폭발 드럼통, 모래주머니, 철조망, 무전기, 화살표, 철문, 레버, 경고등 |
| `interactive/` | 손상된/파괴된 상자, 폭발 드럼통, 열린 문, 켜진 레버, 스테이지 클리어 깃발 |
| `scenery/` | 작은 사구, 바위산, 먼 산, 마른 나무, 감시탑, 덤불 |
| `items/` | 체력팩, 탄약상자, 샷건, 수류탄, 중기관총, 점수 메달 |
| `effects/` | 탄환·탱크포탄·수류탄, 총구 섬광, 피격 스파크, 모래 먼지, 폭발 3종 |
| `hud/` | 플레이어 초상화, 체력·탄약·수류탄 아이콘, 메달, 타이틀·메뉴·클리어 글자, 숫자 0~9, HP 바 |
| `backgrounds/` | 가로로 긴 원본 사막 배경, 1280×720 화면용 배경 |
| `sheets/` | 생성된 원본 아틀라스 이미지 |

## 권장 게임 구조

1. WASD 또는 방향키로 캐릭터 이동, 스페이스로 점프
2. 공격 키로 총알을 발사하고, 별도 키로 수류탄 투척
3. 적 병사와 자동 포탑을 물리치며 오른쪽으로 이동
4. 탄약과 체력 아이템 획득
5. 폭발 드럼통을 쏘면 폭발, 나무상자는 파괴 가능
6. 맵 끝의 탱크 보스를 파괴한 뒤 체크무늬 깃발에 도착하면 클리어

## 프레임 재생 예시

| 애니메이션 | PNG 순서 | 권장 간격 |
| --- | --- | --- |
| 달리기 | `player/run_01.png` → `run_02.png` | 90~120ms |
| 적 병사 걷기 | `enemies/soldier_walk_01.png` → `soldier_walk_02.png` | 130~160ms |
| 탱크 이동 | `boss/tank_idle.png` ↔ `tank_roll.png` | 150ms |
| 피격 효과 | `player/hit_flash.png` ↔ `player/hit.png` | 짧은 반복 |
| 상자 파괴 | `props/wooden_crate.png` → `interactive/crate_damaged.png` → `crate_broken.png` | 게임 상태에 따라 |
| 탱크 파괴 | `boss/tank_damaged.png` → `tank_explosion.png` → `tank_wreck.png` | 게임 상태에 따라 |

좌우 이동에는 이미지 수평 뒤집기를 사용해도 됩니다. 게임 화면의 충돌 영역은 원본 이미지 전체가 아닌 실제 캐릭터 몸체에 맞춰 조정하세요.

## 출력 규격

- 캐릭터 PNG: 기본 128×128px
- 적 포탑: 144×128px, 탱크: 256×176px
- 맵 타일: 64×64px
- 맵 소품/이펙트: 128px 안팎
- 대부분 투명 RGBA PNG, 배경만 불투명 PNG
- 중기관총 픽업은 가로가 긴 192×96px

이미지 생성 후 일정한 캔버스로 자르고 알파 영역을 정리했습니다. 프레임마다 자세와 비율이 조금 다를 수 있으며, 엄밀히 이어 붙이는 타일 경계는 게임 화면에서 추가 점검하세요.

이 팩에는 게임 코드·맵 데이터·충돌 데이터·사운드 파일은 들어 있지 않습니다.
