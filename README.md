# 메탈슬러그 스타일 2D 횡스크롤 슈팅 게임 기획서

**프로젝트:** GameCraft 2D 게임 개발 프로젝트  
**작성자:** 오희성  
**시작일:** 2016.10.15  
**제출 목적:** 기말고사 과제형 제출

## 1 프로젝트 개요

메탈슬러그의 빠른 이동과 사격 방식에서 아이디어를 얻은 1인용 2D 횡스크롤 액션 슈팅 게임이다. 플레이어는 적 기지를 돌파하면서 등장하는 적을 처치하고, 스테이지 마지막에 있는 보스를 쓰러뜨리면 게임을 클리어한다. 기말 과제의 개발 기간을 고려하여 완성 가능한 스테이지 1개에 집중한다.

| **항목**    | **기획 내용**                                                            |
|-------------|--------------------------------------------------------------------------|
| 게임 장르   | 2D 횡스크롤 액션 슈팅                                                    |
| 플레이 방식 | PC 키보드 / 1인 플레이                                                   |
| 개발 환경   | C++ 및 Visual Studio 기준, 세부 그래픽 구현 방식은 수업 환경에 맞춰 결정 |
| 핵심 목표   | 이동, 점프, 사격, 적 충돌, 스테이지 진행, 보스전 구현                    |

## 2 게임 진행 방식

시작 화면에서 게임을 시작하면 플레이어가 기지 입구에 등장한다. 오른쪽으로 이동하면서 일반 적과 포탑을 상대하고, 회복 또는 무기 아이템을 획득해 전투를 이어 간다. 마지막 구간에서는 보스가 등장하며 보스 체력을 모두 줄이면 클리어 화면으로 이동한다. 체력이 0이 되면 게임 오버 화면에서 처음부터 재시작할 수 있다.

핵심 흐름 시작 화면 → 스테이지 전투 → 보스전 → 클리어 / 게임 오버

## 3 플레이어 조작 및 전투

| **키** | **동작**  | **설명**                                        |
|--------|-----------|-------------------------------------------------|
| A / D  | 좌우 이동 | 지형을 따라 이동하며 화면이 오른쪽으로 스크롤됨 |
| Space  | 점프      | 적 공격 회피 및 낮은 장애물 통과                |
| J      | 총 발사   | 캐릭터가 바라보는 방향으로 총알 발사            |
| K      | 수류탄    | 보유 수량을 1개 소비하여 범위 공격              |
| S      | 앉기      | 낮은 자세로 적의 일부 공격 회피                 |

- 플레이어의 기본 체력은 3이며, 피격 시 일정 시간 추가 피해를 받지 않도록 처리한다.

- 기본 권총은 탄약 제한 없이 사용하며, 보급 아이템을 먹으면 일정 탄수가 있는 기관총으로 변경된다.

- 총알이 적과 충돌하면 적 체력이 감소하고, 적 체력이 0이 되면 피격·폭발 효과 후 제거된다.

## 4 스테이지 및 등장 요소

배경은 적의 군사 기지로 설정한다. 지형은 시작 구역, 일반 전투 구역, 포탑 구역, 보스 구역으로 구분한다. 스테이지는 하나의 긴 맵으로 제작하며, 카메라는 플레이어의 이동을 따라간다.

| **구분** | **등장 요소**             | **역할**                             |
|----------|---------------------------|--------------------------------------|
| 일반 적  | 적 보병                   | 짧은 거리 순찰 및 단순한 총격        |
| 고정 적  | 포탑                      | 제자리에 배치되어 일정 간격으로 발사 |
| 보스     | 장갑차                    | 높은 체력과 반복되는 총격 패턴 보유  |
| 아이템   | 체력 회복, 기관총, 수류탄 | 생존 및 공격 능력 보강               |
| 지형     | 바닥, 발판, 장애물        | 이동과 점프, 전투 동선을 구성        |

## 5 화면 구성

- 시작 화면: 게임 제목과 시작 방법 표시

- 게임 화면: 캐릭터와 적, 배경 및 상단 HUD(체력·무기·수류탄 수) 표시

- 게임 오버 화면: 체력 0일 때 결과와 재시작 안내 표시

- 클리어 화면: 보스 격파 시 결과와 재시작 안내 표시

## 6 필요한 이미지와 사운드

| **종류**  | **필수 리소스**                                        |
|-----------|--------------------------------------------------------|
| 플레이어  | 대기, 달리기, 점프, 사격, 앉기, 피격 프레임            |
| 적과 보스 | 보병 이동·사격·피격, 포탑, 장갑차 보스, 파괴 연출      |
| 전투 효과 | 총알, 수류탄, 폭발, 명중 효과, 아이템 획득 효과        |
| 배경·UI   | 기지 배경, 바닥·발판, 시작·결과 화면, 체력·탄약 아이콘 |
| 사운드    | 총소리, 폭발음, 피격음, 아이템 효과음, 배경 음악       |

## 7 개발 범위와 우선순위

필수 구현은 플레이어 이동과 점프, 총알 발사, 충돌 처리, 적 2종, 보스 1종, 스테이지 1개, 체력 표시와 게임 결과 화면으로 정한다. 이후 시간이 남으면 수류탄, 기관총 보급, 피격 이펙트와 사운드를 추가한다. 복잡한 적 인공지능, 여러 스테이지, 멀티플레이 기능은 이번 과제 범위에서 제외한다.

## 8 제작 일정

| **구간** | **작업 내용**                           | **확인할 결과**                |
|----------|-----------------------------------------|--------------------------------|
| 1단계    | 게임 화면과 플레이어 이동·점프 구현     | 캐릭터가 지형 위에서 정상 작동 |
| 2단계    | 총알 발사, 충돌 판정, 적 캐릭터 구현    | 적 공격과 처치가 가능          |
| 3단계    | 스테이지 배치, 카메라 이동, 보스전 구현 | 시작부터 보스까지 플레이 가능  |
| 4단계    | UI, 이미지·사운드 보완, 오류 수정       | 게임 오버·클리어까지 완주 가능 |

## 9 완성 기준과 테스트

- 이동, 점프, 앉기, 사격이 서로 충돌하지 않고 정상 작동하는지 확인한다.

- 총알과 적, 플레이어와 적 공격의 충돌 판정이 정상인지 확인한다.

- 적 처치·아이템 획득·보스 격파 후 화면 상태가 올바르게 변경되는지 확인한다.

- 게임 오버와 클리어 후 재시작해도 체력, 탄약, 적 배치가 초기화되는지 확인한다.

최종 목표는 모든 기능을 크게 늘리는 것이 아니라, 한 스테이지를 처음부터 끝까지 오류 없이 즐길 수 있는 게임을 완성하는 것이다.
